# Perfil público de la organización

Este repositorio contiene el perfil público de la organización `bitclick-solution` en GitHub. GitHub muestra el contenido de [profile/README.md](profile/README.md) en la página principal de la organización cuando este repositorio se llama `.github` y es público.

## Cómo actualizar el perfil

1. Edita `profile/README.md`.
2. Haz commit y push a `main`. GitHub actualiza la página de la organización al momento.

## Reglas de contenido

El texto del perfil sigue las reglas editoriales de `BITCLICK/web/PRODUCT.md`:

- No nombres proveedores de modelos LLM: escribe "agentes LLM" o "el modelo configurado".
- No publiques tarifas, importes de proyecto ni descuentos, en ninguna forma.
- Atribuye siempre las métricas (horas recuperadas, ahorro de licencias) a Publiexpe por nombre; no las presentes como resultado general.
- No inventes clientes, testimonios, logos ni métricas. Publiexpe y Agrodelta tienen autorizado el uso de nombre y logo.
- No enlaces repositorios privados de la organización: el enlace da 404 al visitante.
- Evita afirmaciones absolutas de soberanía ("nunca en nubes ajenas"): Agrodelta corre en cloud gestionado.
